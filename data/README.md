# 提示词数据集

本目录的数据由 `scripts/build_dataset.py` 确定性生成，不包含外部网页或受版权保护的数据集文本。

- `smoke.jsonl`：不超过 24 条，只用于快速检查代码链路。
- `candidate.jsonl`：60%，用于敏感度计算、优化和 MCC 指纹选择。
- `validation.jsonl`：20%，用于阈值、核带宽和统计方法校准。
- `test.jsonl`：20%，只用于最终评估。

任务类别包括数学、推理、逻辑、知识、翻译、代码、结构化输出、摘要、安全、指令遵循和长上下文。客观题尽可能提供 `expected_answer` 或 `expected_contains`，开放任务不假设唯一答案。

所有样本包含稳定 ID、类别、语言、来源和 split。修改生成脚本后必须重新运行，并在实验记录中保存数据文件哈希。
