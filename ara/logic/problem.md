# Problem

The project asks whether task-preserving prompts can form a robust integrity fingerprint for the fixed `Qwen/Qwen2.5-14B-Instruct` revision across pruning, quantization, Gaussian-noise, and fine-tuning perturbations.

Experiment E showed that a provenance-preserving 30-prompt union was not jointly robust enough under one new seed set. Experiment F1 therefore tested whether a frozen multi-seed development ranking over the original 64-row portfolio could select a balanced 30-prompt set for independent confirmation. G1 stable-component/MCC extraction and H1 prompt-stratified MMD were explicitly conditional on the parent gates.

The closing gap is categorical source sufficiency: the F1 portfolio did not contain enough eligible unique-source logic and summary candidates to satisfy the frozen three-per-category selection quota.
