# Fingerprint V2：独立校准全局覆盖率闭环

V2从`v1-fingerprint-closed-loop`建立独立分支，不覆盖V1。它保持V1的组件提取规则和提示词分层MMD不变，新增独立广覆盖校准集、固定全局可观察组件集合、三个覆盖率分解及全局非加权MCC12。

严格表述为“独立广覆盖校准集估计下的模型全局可观察关键组件集合”，不声称获得数学意义上的模型全部关键组件。

校准数据由14个任务族组成。初始协议的每族12条构建提示词和4条审计提示词未通过预先冻结的饱和度与审计新颖度门禁，因此在任何V2端点实验运行前，按失败处理扩展为每族20条构建提示词和4条审计提示词，共336条。门禁阈值、组件定义、攻击参数和统计方法均未改动；扩充决策及初始失败数值记录在`calibration_expansion_record.json`。这些校准提示词不参与最终MMD验证，也不根据V1或V2攻击结果选择。

主选择目标为全局集合上的非加权MCC；V1权重和类型均衡权重只作消融。V2重新生成参考与目标响应，形成独立下游验证结果。

最终门禁与覆盖率结果：

- 336条校准提示词形成36,561个经验全局可观察组件；
- 最后三个平衡批次相对新增率为0.44%、0.60%、0.44%，均低于2%；
- 审计集新颖度为3.44%，低于8%；
- 候选可达覆盖率为27.78%，MCC12选择效率为97.11%，最终全局覆盖率为26.98%；
- 注意力、FFN、attention residual、MLP residual最终覆盖率分别为98.12%、25.48%、100%、100%；
- 7个端点共840次目标查询，分层MMD正确判断6/7个状态，检出5/6个修改状态，完整模型无误报；
- 唯一假阴性为std_ratio=0.001的高斯噪声，不能据此宣称对所有小幅参数修改有效。

完整运行入口：

```bash
bash scripts/run_fingerprint_v2_all.sh
```
