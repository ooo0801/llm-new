# Fingerprint V1（现有 16 条闭环）

本版本把 V6 冻结测试严格通过的 16 条离散优化提示词作为固定输入，依次完成激活覆盖提取、MCC 从 16 选 12、参考响应指纹固化、提示词分层 MMD 和独立模型状态验证。

版本边界：本次不处理类别缺口，也不追加提示词。未来若扩展候选池，应建立新版本并重新运行激活、MCC、参考指纹及全部端点实验，不能把两版结果混合。

主统计方法是提示词分层 MMD；pooled MMD 只作为申请书原方法的消融基线。每条提示词保留独立重复响应和 `prompt_id`，置换仅在同一提示词内交换模型标签。999 次置换使用 `(b+1)/(M+1)` 修正，最小可报告 p 值为 0.001。

运行入口：

```bash
bash scripts/run_fingerprint_v1_all.sh
```

运行期大文件、模型权重、LoRA 适配器和原始响应位于 `results/fingerprint_v1_20260730/`，不进入 Git。完成后，本目录只收录冻结清单、协议、指纹和精简结果。
