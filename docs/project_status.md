## 当前研究阶段

项目尚未进入“建立指纹”阶段，当前完成的是其前置阶段：生成对模型修改敏感、能够形成离散文本、并通过任务与五家族外层约束的候选提示词。

已完成的主链路为：

1. 从 336 条候选提示词中冻结 60 条正式内层输入；
2. 使用小参数块微观代理和五家族宏观代理计算联合搜索方向；
3. 使用 HotFlip 候选分数执行离散 token 修改，并在每轮满足约束时提交；
4. 对正式生成结果建立候选组合；
5. 使用固定微观/宏观校准参数进行开发集完整外层重排；
6. 冻结开发集选择；
7. 使用预注册、与开发选择隔离的攻击清单进行冻结测试。

## 已解决的主要瓶颈

- 连续嵌入优化只投影检查、不提交 token，导致 60 条结果实际均未形成离散修改；现已改为候选离散替换、验收后提交。
- 仅比较位移与最近边界忽略方向性；现使用联合梯度对候选嵌入差进行 HotFlip 排序，并以真实代理重新评估。
- 结构化 FFN 剪枝的高级索引写入没有修改原权重，导致该家族得分与梯度为零；现已改为原位索引写入并加入测试。
- 不同代理的梯度尺度相差数千倍；现使用固定、分代理校准，分别记录范数并进行异常裁剪后再合并。
- V5 的 knowledge 单样本结果受最小尺度回退影响产生虚假大增益；现使用 12 条开发初始提示词拟合固定 log1p 中位数/MAD 校准。
- 正式 60 条完成后，候选组合器把初始任务验证记录误当成优化轮次，触发 `KeyError: 'round'`；现跳过无轮次 provenance 记录并加入回归测试。
