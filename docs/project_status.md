# 项目状态（Fingerprint V2 全局校准闭环）

更新时间：2026-07-31

## 当前研究阶段

项目已经在 V6 前置基线上完成 V1 和 V2 两个独立指纹闭环。V1 固定使用 V6 冻结测试严格通过的 16 条优化提示词，并以它们的组件并集作为覆盖率分母；V2 保持这 16 条为候选，新增 336 条独立广覆盖校准提示词来估计全局可观察组件分母。

已完成的完整主链路为：

1. 从 336 条候选提示词中冻结 60 条正式内层输入；
2. 使用小参数块微观代理和五家族宏观代理计算联合搜索方向；
3. 使用 HotFlip 候选分数执行离散 token 修改，并在每轮满足约束时提交；
4. 对正式生成结果建立候选组合；
5. 使用固定微观/宏观校准参数进行开发集完整外层重排；
6. 冻结开发集选择；
7. 使用预注册、与开发选择隔离的攻击清单进行冻结测试。
8. 对 16 条严格通过提示词进行两次注意力、SwiGLU FFN 和残差激活提取；
9. 用加权最大新增覆盖从 16 条选择 MCC12；
10. 固定模型/tokenizer revision、生成参数和 10 组参考响应；
11. 保留 `prompt_id` 层级，运行提示词分层 MMD 及 pooled MMD 消融；
12. 对完整模型和六个隔离修改端点完成统计判定并发布校验和。

## 已解决的主要瓶颈

- 连续嵌入优化只投影检查、不提交 token，导致 60 条结果实际均未形成离散修改；现已改为候选离散替换、验收后提交。
- 仅比较位移与最近边界忽略方向性；现使用联合梯度对候选嵌入差进行 HotFlip 排序，并以真实代理重新评估。
- 结构化 FFN 剪枝的高级索引写入没有修改原权重，导致该家族得分与梯度为零；现已改为原位索引写入并加入测试。
- 不同代理的梯度尺度相差数千倍；现使用固定、分代理校准，分别记录范数并进行异常裁剪后再合并。
- V5 的 knowledge 单样本结果受最小尺度回退影响产生虚假大增益；现使用 12 条开发初始提示词拟合固定 log1p 中位数/MAD 校准。
- 正式 60 条完成后，候选组合器把初始任务验证记录误当成优化轮次，触发 `KeyError: 'round'`；现跳过无轮次 provenance 记录并加入回归测试。

## 结论边界

可以声明：现有 16 条已完成 V1 端到端闭环；V2 又在冻结的 336 条独立校准集下建立了经验全局可观察组件分母，MCC12 覆盖其中 26.98%，并在本次七状态实验中检出 5/6 个修改状态。分层 MMD 修复了 pooled MMD 在多种修改上的假阴性。

不能声明：36,561 个组件等于模型全部关键组件，上述单实例指标等于完整攻击分布上的最终检测率或总体 FPR，或 NF4 是严格整数 INT4。
