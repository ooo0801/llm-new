## 1. 研究问题与方法说明

### 1.1 问题、贡献定位和威胁模型

希望解决的问题：在云端LLM只允许少量输出查询时，发现相对于可信原模型的微小参数修改，尤其是高斯扰动和LoRA微调；进一步考察敏感提示词能否改善同预算检测，减少达到相同检测表现所需的查询数。

**目前最有证据的贡献表述**：提出并实现“局部参数敏感性＋多修改实例输出差异”的提示词优化与归一化流程；在固定7B模型、固定首token检测协议下，同来源配对实验发现敏感改写相对其原文有明显检测增益。贡献新颖性还需与已有工作系统比较；不是仅凭现有数据就能宣称A会贡献充分。

以下不能作为已成立的主贡献：双层结构不可替代、MCC优于Top、全面优于RESF、未见攻击泛化、32B验证。对应直接证据缺失或当前对照不支持。

### 1.2 方法流程

`400普通母池 → 100校准/300待优化 → 冻结80实际搜索来源 → 接受61改写 → 统一敏感度评分和激活覆盖提取 → MCC/Top各取4、8 → 可信模型参考/MC → 首token采样 → E/P检验 → 面板报警`。

另一个已经完成的支路：把最后四个敏感面板逐条还原为原来源文本，不重新排序；补采普通侧参考、MC和输出，做同端点同预算配对比较。

指纹是选出的提示词集合；参考概率是参考数据；解码、检验、阈值是检测协议；m和n是预算配置。不要混为一个不加区分的“指纹算法”。

### 1.3 关键公式与实现

令z(x)为可信原模型在首个输出位置的全词表logits，W_b为选定参数块，e(x)为输入embedding。校准使用七块q0/k9/v18/o27/gate0/up9/down18。

**微观分数**（8个Rademacher ±1探针）：

\[
M_b(x)=\frac1{8}\sum_{r=1}^{8}\|\nabla_{W_b}(v_r^Tz(x))\|_F^2,
\qquad s_b=\operatorname{median}_{x\in C}M_b(x).
\]

这估计的是局部logits—参数Jacobian平方范数；不是熵梯度，也不是最终检出率。离散搜索还求微观分数对输入embedding的梯度。源码：`code/frozen/src/llm_integrity/inner_micro_proxy.py`。

**宏观JS目标**（全词表、温度1，无top-k/top-p）：

\[
JS(p,q)=\tfrac12 KL(p\|a)+\tfrac12 KL(q\|a),\quad a=(p+q)/2,
\]
\[
D_f(x)=\tfrac15\sum_{j=1}^{5}JS(p_0(\cdot|x),p_{f,j}(\cdot|x)),\quad
m_{f,c}=\operatorname{median}_{x\in C_c}D_f(x),\quad
s_f=\exp\{\tfrac14\sum_c\log m_{f,c}\}.
\]

每族先在每条提示词上平均五变体，再各类别取中位数，四中位数等权几何平均。五族分别除以各自尺度，不能把五尺度平均成一个公共分母。宏观梯度先平均完整向量，再取范数。类别中位数≤1e-20或非有限判无效，不临时加平滑常数/换样本。源码：`macro_proxy.py`、`scripts/run_calibration_7b_100_geo.py`、`scripts/calibration_geo_stats.py`。

**权重与统一评分**：设g_{x,b}=‖∇e M_b(x)‖，h_{x,f}=‖(1/5)Σ_j∇e JS_{f,j}(x)‖。

\[
\lambda_{raw}=\frac{\operatorname{median}_{x,f}(h_{x,f}/s_f)}{\operatorname{median}_{x,b}(g_{x,b}/s_b)},\quad
\lambda=\mathrm{clip}(\lambda_{raw},0.1,10),
\]
\[
S(x)=\lambda\,\frac17\sum_b M_b(x)/s_b+\frac15\sum_f D_f(x)/s_f.
\]

实现对100×7、100×5数组分别直接取中位数，**不是先按提示词平均梯度再取中位数**。λ=9.619061603348785，宏观权重1；七微观、五宏观精确尺度及区间在 `settings/scales_weights.json`、`settings/calibration_statistics.json`。权重是启发式平衡量，不是统计最优性结论。

搜索：5轮、8探针、4候选位置、每位置16候选、精排8、最大长度128、编辑比例≤0.5、五族均通过不退化门槛（1%相对容忍）。并非每次迭代都重新计算七块，搜索有balanced分块调度；候选最终排名才统一覆盖七块。**语义/任务保持、表面兼容、困惑度约束均未启用**。完整设置见 `settings/fingerprint_plan.json`；代码 `discrete_joint_inner_optimizer.py`。

**Top与MCC**：Top按S降序；MCC令A(x)为稳定激活组件集合，贪心选

\[
x^*=\arg\max_{x\notin F}\sum_{c\in A(x)\setminus\cup_{y\in F}A(y)}w_c.
\]

attention/FFN/attention-residual/MLP-residual权重1.2/1/0.8/0.8，两次profile交集、Jaccard≥0.999。当前调用没有传metadata，因此增益平分仅用稳定ID，而不是类别新颖度/稳定性二次排名。覆盖分母仅61候选组件并集，不是全部模型。见 `mcc.py`、`activations.py` 和 `diagnostics/selection_trace_coverage.json`。

**E/P检测**：对每个提示词，q_t是可信模型按温度t∈{0.5,0.7,0.9}和实际top-k/top-p构建的首token概率；完整保留三个解码后支持集的并集U。

- E：样本token不在U则报警。当前声明的有限零假设族中U外质量恰为0，所以E可在整个n窗口检查。不是论文中随意截断Top-K后仍有非零尾部的情形。
- P：计数N_v，经验频率N_v/n；统计量

\[
T(N)=\min_t 2\sum_{v:N_v>0}N_v\log\frac{N_v/n}{q_t(v)}.
\]

某q_t对已观察token概率为0时该成员偏差为∞，再取族内最小。每个成员独立MC模拟B=10000次，用同一T重算。p_t=(1+#\{T_b≥T_obs\})/(B+1)，最终p=max_t p_t。

- 面板α=.05；每prompt分配α_E=.01/m、α_P=.04/m。**本轮每个n单独终点检验**，故没有再除3；通用代码多look模式会再分配look预算，但当前并未把25/50/80作为一次共同序贯检验。
- m4的P阈值0.01，m8为0.005；E预算分别0.0025、0.00125。任一提示词报警即面板报警。
- 理论适用范围是声明的有限参考族和相应IID条件；12配置未共同校正。MC/支持集浮点和解码身份必须一致。

源码：`code/frozen/src/llm_integrity/resf_token.py`、`code/frozen/scripts/evaluate_prompt_budget.py`。不能把归一化尺度当成E/P阈值。

### 1.4 相对RESF/ESF的沿用与改动
